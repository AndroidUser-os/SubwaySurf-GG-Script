# SubwaySurf-GG-Script

Clean GameGuardian Lua scripts for **Subway Surfers**, split into a classic refine tool for older builds and a multi-part setup for newer IL2CPP versions.

## Files in This Repository

- `retro_subway.lua` — Minimalist script built around manual search, `Refine`, and `Edit All` workflows for older game versions.
- `Subway_Menu.lua` — Main launcher / menu script for the multi-part script set.
- `Subway_Modern.lua` — Module aimed at newer game builds / IL2CPP structures.
- `Subway_Old.lua` — Companion module for legacy / older build handling within the multi-part set.

## How to Use

1. Launch **Subway Surfers** and attach **GameGuardian**.
2. Open GameGuardian's script menu and load the `.lua` file matching your game version.
3. Follow the on-screen prompts (for `Refine`-based steps, change the value in-game, open GameGuardian again, and enter the updated value).

## Notes

- Compatibility can vary depending on the game version, architecture, and memory layout.
- For offline/single-player testing and experimentation only.
